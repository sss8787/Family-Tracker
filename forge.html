Backup & Device Sync

Storage used
Local backup (one file, everything)

Exports roster, relationships, scenes, arcs, consult threads, and attached stories as a single file. Restore replaces everything on this device with the backup's contents.

GitHub Gist sync (between devices)

Uses a private GitHub Gist as your sync store. Create a token at github.com/settings/tokens with ONLY the "gist" scope, paste it below on each device. Push uploads this device's data; Pull replaces this device's data with the gist's.

Rank them in

The forge will infer their personality from source material or historical record, with reasoning shown alongside the portrait. With search on, it looks the figure up first and cites what it found — slower and slightly costlier, but the typing rests on retrieved evidence rather than recollection. Worth it for obscure figures; unnecessary for household names. Attest only forces a capability-only card for figures whose record is loud about deeds and silent about interiority — leave it off and the forge still drops the types on its own where the record cannot bear them; there is deliberately no switch that forces typing the other way. The anchor pins this figure above or below someone already in the project on one stat: use it where you know the ordering from the sources, not to make someone strong — if the record refuses the pin the forge will score honestly and say so.
